# Canon Bundle (v0.1) — Dev Wedge, Local

This bundle is a deployable slice of the Interpretive Fabric (Domain Pack + Prism) executed locally
in the dev wedge repo.

## Execution-contract alignment
- Domain Pack returns: semantic interpretation, expectation evaluation, interpretive signals, narrative fragments.
- Prism returns: perspective significance, rationale, sensitivity.
- OS assembly (in this repo) assembles narrative and emits the meaning artifact.

No directives emitted in dev wedge.

## Promotion
Runtime must refuse to execute unless `promotion.yaml.status == "promoted"`.

## Determinism & immutability
- Domain Pack semantics are immutable once loaded; changes require new version.
- Meaning artifacts must stamp domain_pack_id/version and prism_id/version.

## Integrity
- `artifacts/bundle.index.json` is generated by the hash builder.
- `computed.canon_hash` must match recomputation.
